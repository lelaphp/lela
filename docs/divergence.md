# Divergences

Every accepted difference from the oracle, one row per divergence key: a
witness hash, a phpt path, a compile-identity path or a trace site
(`harness-design.md` §4.3). The truth is `divergence.toml`; this page is its
rendering by `xtask status --section divergence`, kept current by `computed
run` and held by `computed check`. A person writes a row and its reason;
`compare`'s caller or the fuzzer proposes one with status `open`, and `done`
fails while an open row touches the scope.
