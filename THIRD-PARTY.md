# Third-party notices

How to read this: component | where in this project | origin | licence | notice text (verbatim).

Every notice text is a file in `LICENSES/`, copied byte for byte from the file the last column names: the component's own licence file, an item of php-src's `README.REDIST.BINS`, or the comment that carries the notice in php-src's source, all at php-src's tag php-8.5.12. Paths under "origin" are php-src's. `NOTICE` says how the code derived from php-src itself is used.

## 6. Rust crates

The crates this project builds with are the ones `Cargo.lock` lists, each under the licence its own manifest states; `cargo metadata --format-version 1` prints each package's `license`. The list changes with `Cargo.lock`, so it is not typed here.
